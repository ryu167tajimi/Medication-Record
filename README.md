# TAJIMI MED AIDE Ver.3.7

GitHub Pagesに公開するには、`index.html` をリポジトリのルートへアップロードしてください。

## 改善
- 撮影原画像の表示を維持
- タッチ操作でOCR対象の範囲を選択（薬剤名部分を切り出し）
- OCR解析画像を実際の入力Blobから表示し、取り違えを診断
- 切り出し画像を最大3倍拡大、最大3000px
- 選択範囲では日本語OCRのページ分割モードを変更
- 日本語文字の割合・OCR信頼度が低い場合に警告
- OCR原文と薬剤名候補を別々に表示し、候補は自動確定しない

## 注意
OCRは100%正確ではありません。薬剤名・規格・剤形は原画像と照合してください。既往症は薬剤だけでは確定できません。公開サイトに患者情報を入力しないでください。OCRライブラリ・日本語学習データは外部CDNから読み込みます。Android実機での動作は未検証です。
