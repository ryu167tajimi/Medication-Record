# TAJIMI MED AIDE Ver.3.6

GitHub Pagesに `index.html` をアップロードしてください。医薬品マスターはHTMLに内蔵されています。

## 修正点
- 外部カメラアプリ起動時の画面非表示イベントで撮影済み画像を消さない
- 新しい写真を選択したら以前のOCR文字と候補を消去
- 画像の世代番号を確認し、古い画像のOCR結果を反映しない
- OCR自動回転を無効化し、撮影確認画像と解析対象の対応を明確化
- 強い画像補正は初期状態OFF。OCR文字と薬剤推定は別工程

## 注意
Android実機での検証は未完了です。日本語OCRの誤読は完全には防げません。OCRプログラムは外部CDNから取得します。個人情報を含む画像は使用しないでください。
